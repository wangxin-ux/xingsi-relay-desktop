# 星思天玑客户端

## 产品与边界

Windows 桌面发行版使用星思天玑名称和中转站 logo；保留 ZCode 的 Apache-2.0 许可证和第三方声明。独立应用身份和数据目录，不覆盖 ZCode。发行包不得含开发者的账号、密码、API Key 或用户数据，不接受上游 ZCode 自动更新。

## 登录与状态所有者

入口为中转用户邮箱、密码。固定 HTTPS 站点，禁止动态 origin、跳转泄露凭据。Desktop platform 的登录适配器完成 `/api/v1/auth/login`、订阅查询、分页密钥查询和 `/v1/models` 探测，不记录或持久化密码/JWT。支持站点 TOTP 登录挑战；验证码等尚不支持的挑战须明确报错。

Provider Settings Service 是模型配置唯一持久化所有者。UI 通过 hook 调用 platform，并通过已有 Provider Settings Service 保存账号专属 provider、密钥和完整模型名单。登录成功只在模型探测和配置提交成功后发布；重登同一账号更新原 provider，不产生重复实例。不同账号不得复用上一个账号的密钥或模型列表。

事件顺序：邮箱/密码 → platform 登录适配器 → 站点 JWT → 订阅/密钥 → 有效密钥模型探测 → Provider Settings Service 提交 → API Key 登录成功事件 → 主工作台。

优先有效订阅对应的有效文字密钥，排除停用、过期、额度耗尽密钥；没有可用密钥时用用户自己的有效订阅组创建一个“星思天玑”密钥（不得改变订阅、额度、旧密钥或管理员设置）。没有订阅或可用文字模型时显示可理解的错误。订阅查询失败不得冒充无订阅。模型缺 GLM 时选账号实际可用的文字模型。请求有超时；失败不记录凭据，不显示含凭据的原始响应。

UI 禁止重复提交。异步结果只提交给发起登录的当前表单；卸载表单时忽略未完成结果。密码仅在本次登录内存中，失败可重试，成功清空。无需用户复制 API Key 或配置 MCP。

## 验收

品牌替换不得进入 HTTP 请求头（User-Agent、X-*、HTTP-* 的字段名、固定值和模板片段）；这些网络协议字段保留原英文 ASCII，避免 fetch Headers 的 ByteString 转换失败。回归覆盖真实运行时中的请求头片段与 Headers 构造，以及 Agent 身份中文展示仍有效。模型切换提示与模型按钮一致，仅显示模型名称，不显示中转 provider 名称或邮箱。

品牌展示：内置官方 zcode-guide 插件的卡片、管理列表、详情统一显示“星思中转指导指南”，说明与示例提示移除旧产品名称，图标复用客户端的紫色星环。通过完整插件 ID 匹配，兼容已经缓存的旧 listing，第三方同名插件不覆盖。Agent 的交互式身份、CLI 前缀及内置子代理身份使用“星思中转助手”，明确用户询问身份时按该名称回答，历史对话中的旧自述不代表当前身份；保留工具、安全和输出风格约束。调试构建在独立原版运行时副本中仅替换字符串文本，不改变内部协议 ID、路径、许可证、版权声明或代码标识符。旧指南的文档、命令描述一起替换展示品牌，保留代码路径与协议名称。安装包继续冻结。

Composer 模型选择器的按钮与悬浮提示仅显示模型名称，不显示 provider 名称或账号邮箱。保留内部 provider ID 和原有模型切换路径，账号身份继续由侧栏 session 投影显示。

额度条与百分比都表示剩余额度：100% 填满绿条，消耗后按剩余百分比缩短，0% 空条；无可用数据时不显示填充。进度条辅助标签为“剩余额度”。账号菜单和退出相关命令统一使用“退出登录”文案，复用现有退出流程与 session 清理，不新增登录状态所有者。

额度卡在百分比左侧提供手动刷新按钮，与每分钟自动刷新共用 platform 读取路径；请求中禁用按钮并显示旋转图标，卸载或切换账号忽略旧响应。优先从 `/api/v1/subscriptions/progress` 的 subscription/progress 配对读取实际日、周、月 limit_usd/used_usd，避免订阅 group 缺少限制字段时丢失额度。登录时额度读取失败不阻止模型配置；后续刷新明确显示暂不可用。未知额度显示“暂无额度信息”，查询中显示“查询中”，不得显示绿色破折号或伪造百分比。session store 继续唯一持有额度数据，UI 仅持有请求状态；安装包不更新。

每次程序启动必须先完成中转登录，即使磁盘已有 API Key，也不能据此绕过登录页。中转登录态由独立内存 session store 唯一持有，不混入上游 OAuth user，也不持久化密码/JWT/登录态。仅在账号模型配置提交成功后建立 session；Root 依据该 session 阻止工作台渲染和工作区恢复。侧栏从 session 显示真实登录邮箱与账号首字母。退出立即清空 session、返回登录页；已保存模型配置不能代替下次登录，切换账号后由配置流程清理旧账号供应商。旧版本已配置用户首次启动仍需重新登录。

新增验证：已有供应商配置但无 session 时仍要求登录；成功后的邮箱投影；退出/进程重启不保留 session；配置失败不建立 session。

调试品牌改为用户提供快捷方式的「星际中转站」，使用其目标 EXE 的真实图标，启动页仍用大 X。左栏显示当前模型密钥所属订阅组的名称与剩余额度比例（日/周/月限制中最低剩余比例）。额度来自中转订阅 API，登录时读取、登录期间定期刷新；JWT 只留在 Main 内存供额度读取，不传 Renderer、不落盘。读取失败显示未知状态，不能假造 100%。切换/退出账号后旧刷新结果不能写回新账号。界面模式入口移动到 composer 的权限模式右边，复用既有全局 interfaceMode owner，移除头像菜单中的重复入口。安装包继续冻结，只准备调试客户端。

- 正常登录与多密钥/订阅选择；模型名单为站点实际返回。
- 错误密码、TOTP 挑战、分页密钥、停用/过期/额度用尽、空模型、超时。
- 无密钥有订阅时仅创建账号自己的密钥；无订阅不给用户提权。
- 表单提交与失败显示场景（通过组件/静态渲染测试，无浏览器或鼠标）。
- 品牌、独立 appId、禁用官方自动更新、许可证和发布材料完整；安装包不含测试账号。
